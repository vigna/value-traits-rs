# Change Log

## [0.3.0] - 2026-07-13

### Fixed

- The `new_with_range` method of the iterator structures generated by the
  `Iterators` derive macro now checks that the provided range is within
  bounds. The missing check made out-of-bounds accesses reachable from safe
  code.

- The derive macros now propagate the visibility of the type they are applied
  to, so they can be applied to non-`pub` types.

- Empty inclusive ranges (e.g., `2..=1`) within bounds are now considered
  valid by `ComposeRange::is_valid`, mirroring the standard library; derived
  subslices now behave like native slices in this respect.

- The code generated by the derive macros now invokes trait methods using
  fully qualified syntax, so inherent methods of the deriving type cannot be
  called by mistake.

### Changed

- `iter_value_from` now panics when the starting position is greater than the
  length, mirroring slice indexing; previously, the implementations for
  standard types would return an empty iterator, whereas derived
  implementations would panic.

- `SliceByValueMut::copy` now accepts any destination implementing
  `SliceByValueMut` with the same value type, rather than just `Self`.

### Improved

- The structures generated by the derive macros implement `Debug`, and the
  read-only ones implement `Clone`; they are now documented, so they no
  longer cause `missing_docs` warnings in user crates.

- The `VecDeque` implementation of `try_chunks_mut` now documents that it
  calls `make_contiguous`.

- Clippy now runs with `--all-targets` in the CI pipeline.

## [0.2.1] - 2026-02-15

### Fixed

- Fixed iteration on subslices.

- Fixed underflow in `copy`.

### Improved

- Delegation for iterators now match delegations for
  structures (`Rc`, `Arc`, etc.).

- Optimized methods for iterators (`fold`, `map`, etc.).

## [0.2.0] - 2025-10-15

### New

- Radical trait simplification: `SliceByValue` now contains the former
  `SliceByValueCore`; `SliceByValueSet` and `SliceByValueRepl` have been merged
  into `SliceByValueMut`.

- Several new default (mostly default) methods in `SliceByValueMut`, borrowed
  from the `BitFieldSlice` trait of `sux`.

### Changed

- We moved to the 2024 edition.

### Fixed

- `VecDeque` implementations now are gated by the `std` feature, rather than
  the `alloc` feature.

## [0.1.4] 2025-06-21

### New

- Implemented access and iteration traits for `VecDeque`.

### Fixed

- `IterateByValueFrom` delegations were missing a `?Sized`.

## [0.1.3] 2025-06-20

### New

- Four attributes makes it possible to add trait bounds to the
  derive-based implementations of subslices and iterators.

### Improved

- Derive macros are now re-exported from the `value-traits` crate.

## [0.1.2] 2025-06-18

### New

- First release.
